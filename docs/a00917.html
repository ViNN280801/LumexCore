Detailed Description

Export and linkage macros of LumexLib: LUMEX_API, LUMEX_PUBLIC_API, LUMEX_PUBLIC_C_API, LUMEX_UTILITY_API, LUMEX_EXTERN_C_BEGIN and LUMEX_EXTERN_C_END.

LUMEX_API marks a class or function of a shared library: on Windows it is dllexport while LUMEX_EXPORTS is defined and dllimport otherwise, elsewhere it gives default visibility while LUMEX_EXPORTS is defined and is empty otherwise. LUMEX_PUBLIC_API and LUMEX_PUBLIC_C_API (the latter with C linkage) export unconditionally in a source file that defines LUMEX_IMPLEMENTATION before its includes, and equal LUMEX_API everywhere else. LUMEX_UTILITY_API exports only from the utility library itself (LumexCore_utility_EXPORTS defined), so classes with out-of-line static data members are not exported again by every library that includes their header. LUMEX_EXTERN_C_BEGIN and LUMEX_EXTERN_C_END open and close an extern "C" block when compiled as C++.
