Вычисляет CRC4 для заданного 8-битного значения.

Вычисляет CRC4 для заданного 8-битного значения. Функция принимает один байт данных и вычисляет 4-битную контрольную сумму используя предварительно вычисленную таблицу CRC4. Результат используется для проверки целостности данных в коммуникационных пакетах.

Parameters
data8-битное значение для вычисления CRC4. Должно быть в диапазоне 0-255.
Returns
4-битное значение CRC4 (0-15). Результат всегда корректный для любого входного значения.
Note
Функция является потокобезопасной и реентерабельной.
See also
Constants::kCrc4Table

uint8_t packetNumber = 42; uint8_t crc4 = Crc4::calculateCrc4(packetNumber); // crc4 содержит 4-битную контрольную сумму для значения 42
