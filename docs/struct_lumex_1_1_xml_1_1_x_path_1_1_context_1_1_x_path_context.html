Detailed Description

Represents the XPath evaluation context for an expression.

This structure holds the essential components of the XPath context, including the current node, its position within the current node list, and the total size of that node list. This context is critical for evaluating XPath expressions that depend on positional information (e.g., position(), last()).

Note
This struct is designed to be lightweight and is typically passed by const reference during XPath expression evaluation. It is not thread-safe and assumes single-threaded access within an evaluation context.
