Detailed Description

Base64 syntax check.

The pointer and size overload is exported and has the same signature in every C++ standard; the string overload is an inline wrapper over it (string_type_t is std::string_view from C++17 and std::string const & below).

Checks whether size characters starting at str are valid Base64.

Valid Base64 consists of alphabet characters followed by at most two ‘’='`; with padding the length is a multiple of 4, without it the last group has two or three characters. The range needs no terminating NUL and nothing after it is read; a NUL inside the range is invalid.

Parameters
[in]strFirst character; never valid as nullptr, even with a size of 0 (pass "" for an empty input).
[in]sizeNumber of characters to check.
Returns
true if the range is valid Base64 (an empty range is), false otherwise, and always for nullptr.
