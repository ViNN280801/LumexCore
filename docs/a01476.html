Detailed Description

Factory class for creating ILumexSettings instances.

Provides a static method to instantiate settings objects based on the desired configuration file format (INI, XML when LUMEX_SETTINGS_WITH_XML is defined, JSON when LUMEX_SETTINGS_WITH_JSON is defined).

Note
Thread-safe: The factory method is stateless and can be called concurrently.
