Detailed Description

template<typename ErrorType>
class Unexpected< ErrorType >

Класс, инкапсулирующий значение ошибки для Expected.

Этот класс используется для создания объекта Expected в состоянии ошибки. Он является аналогом std::unexpected из C++23.

Template Parameters
ErrorTypeТип хранимого значения ошибки.
Note
Объект Unexpected всегда находится в состоянии ошибки.
