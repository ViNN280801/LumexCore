void lumex::core::exceptions::Wrapper::detail::write_to_stderr ( std::string const &  prefix,
char const *  whatMsg 
)
inline

Writes "prefix. Reason: <whatMsg>\n" to std::cerr using only noexcept operations.

Parameters
prefixHuman-readable context message, already fully built by the caller (e.g. one of the LUMEX_SAFE_CALL* macros) - building it can throw, but that happens before this function is entered, not inside it.
whatMsgThe result of std::exception::what(); may be nullptr.
Note
Deliberately avoids any operation that could itself throw (no further string concatenation, no formatting/logging library) so that reporting a failure can never itself introduce a new one.
