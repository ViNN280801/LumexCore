Специализация для смешанных типов (целочисленный + плавающая точка)

Template Parameters
TПервый тип (целочисленный или плавающая точка)
UВторой тип (плавающая точка или целочисленный)

Реализует безопасное сравнение между целочисленными типами и типами с плавающей точкой. Корректно обрабатывает специальные значения floating-point типов.

Note
Самый сложный случай сравнения, требует особой обработки NaN и бесконечности
