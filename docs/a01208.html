Detailed Description

Represents a pair of XPath allocators for managing expression evaluation memory.

This structure groups two XPathAllocator instances: result for storing final evaluation results and temp for temporary allocations that can be freed frequently during intermediate steps. This separation helps optimize memory usage during complex XPath evaluations.

Note
This struct itself does not manage the lifetime of the XPathAllocator objects it points to; it merely holds references. The actual allocators are typically owned by XPathStackData.
