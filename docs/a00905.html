Finds the iterator whose (projected) value is numerically nearest to value.

Requires the range to be sorted according to pred/proj (uses std::ranges::lower_bound), then compares the found element and its predecessor to pick whichever is closer to value.

Template Parameters
IteratorTypeBidirectional iterator over the range.
SentinelSentinel type for IteratorType.
ValueTypeNumeric type of value (see Detail::NumericConcept).
ProjectionProjection applied to elements before comparison (defaults to identity).
PredicateStrict-weak-order predicate used for the search (defaults to std::ranges::less).
Returns
Iterator to the nearest element, or last if first == last.
