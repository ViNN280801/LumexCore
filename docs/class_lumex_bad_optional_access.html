Detailed Description

Exception thrown when attempting to access the value of an empty LumexOptional.

Global alias for Lumex::Core::Optional::LumexBadOptionalAccess.

This exception class is derived from std::logic_error and is thrown by the value() method of LumexOptional if has_value() is false. It indicates a programming error where an attempt was made to dereference an optional object that does not currently hold a value.

Note
This exception is consistent with std::bad_optional_access in C++17.

This allows LumexBadOptionalAccess to be used without full namespace qualification.
