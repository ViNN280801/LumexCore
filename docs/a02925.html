Formats a point in time as a local-time string, with a robust fallback chain.

Formats a point in time as a local-time string, with a robust fallback chain. Attempts to format time_ as local time (localtime_s on Windows, localtime_r on POSIX). If that fails, falls back to UTC (gmtime_s/gmtime_r). If that also fails, returns the raw number of seconds since the Unix epoch as a decimal string, so this method never throws and never returns an empty string.

Parameters
time_The std::time_t value to format. Defaults to the current system time.
fmtA strftime-compatible format string. Defaults to "%Y%m%d-%H%M%S".
Returns
The formatted timestamp string, or a raw epoch-seconds string as a last-resort fallback.
Note
This method is thread-safe (uses only thread-safe _r/_s time functions and local state).
Does not throw.

std::string log_stamp = LumexTime::timestamp(); std::string custom = LumexTime::timestamp(std::time(nullptr), "%Y-%m-%d");
