template<typename Callable >
bool lumex::core::time::timer::measure_time ( Callable &&  callable,

Optionally gates timing/reporting via an environment variable, then measures callable and writes the result to out.

When need_to_gate_via_env is true, timing and reporting run only if env_name is set (non-empty via is_env_set); otherwise callable is invoked without timing. When need_to_gate_via_env is false, env_name is unused and timing/reporting always run.

Template Parameters
CallableNullary invocable (typically a capturing lambda).
Parameters
callableWork to run (and optionally time).
messageReport label (may be empty).
outOutput stream; defaults to std::clog.
need_to_gate_via_envWhen true, require env_name to be set.
env_nameEnvironment variable name; ignored when gating is off.
Returns
true if timing and reporting ran; false if the env gate skipped them (callable still ran).
