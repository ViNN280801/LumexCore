enum lumex::applied::json::schema::LumexJsonSchemaCheckMode : std::uint8_t
strong

What one walk produces.

validate_only runs every type, required, const and enum check and throws on the first violation, but never builds an output tree (the result is null). validate_and_normalize runs the same checks and also returns the canonical, schema-shaped document: unknown keys are dropped, a missing required leaf becomes null, a missing optional field is omitted. One recursive walk serves both modes so they cannot drift.

enum lumex::applied::json::schema::LumexJsonSchemaFailure : std::uint8_t
strong

Why a document failed schema validation.

parse_error: the text is not JSON. missing_required: a required object or array is absent, or the value is not an object or an array where the schema requires one. type_mismatch: a leaf value does not match type. const_mismatch: a value differs from const. enum_mismatch: a leaf value is not listed in enum.
