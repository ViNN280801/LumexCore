Holds either a value of type SuccessType, or an error of type ErrorType. Functions can return either a success result, or error information without exceptions for expected failures. The implementation uses a union to save memory and manually manages the lifetime of the stored objects. SuccessType Success value type. ErrorType Error type. This implementation is not thread-safe by default. Accessing Expected from several threads without external synchronization is undefined behavior if SuccessType or ErrorType are not thread-safe. Using Expected with types that have non-trivial constructors/destructors or allocate memory, may be slower than C++23 std::expected, because object lifetime is managed by hand. Lets Expected be used for functions that either succeed without returning a value, or return an error. It is the analogue of std::expected<void, E> from C++23. ErrorType Error type. Here has_value() means success without a returned value, and !has_value() means the object holds an error. This enum defines the various statistical distributions that the NumberGenerator class can utilize to produce random numbers. Each enumerator corresponds to a specific distribution type from the C++ Standard Library's <random> header. Users can select the desired distribution when constructing or configuring a NumberGenerator instance.
