Специализация для типов с плавающей точкой

Template Parameters
TПервый тип с плавающей точкой
UВторой тип с плавающей точкой

Реализует безопасное сравнение между разными типами с плавающей точкой. Корректно обрабатывает специальные значения: NaN и бесконечность.

Note
NaN всегда возвращает false для сравнений, бесконечность сравнивается по знаку
