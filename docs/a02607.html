Detailed Description

Exception thrown when attempting to access the value of an empty optional.

This exception class is derived from std::logic_error and is thrown by the value() method of optional if has_value() is false. It indicates a programming error where an attempt was made to dereference an optional object that does not currently hold a value.

Note
This exception is consistent with std::bad_optional_access in C++17.
