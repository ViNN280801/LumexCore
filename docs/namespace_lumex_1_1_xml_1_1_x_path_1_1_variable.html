LUMEX_API bool Lumex::Xml::XPath::Variable::copy_xpath_variable ( XPathVariable * lhs,
XPathVariable const * rhs )
inline

Copies the value of one XPath variable to another.

This function performs a type-aware deep copy of the value from rhs to lhs. It handles the different underlying storage mechanisms for boolean, number, string, and node-set types.

Parameters
lhsA pointer to the destination XPathVariable to which the value will be copied.
rhsA constant pointer to the source XPathVariable from which the value will be copied.
Returns
true if the copy was successful, false otherwise (e.g., memory allocation failure for strings/node-sets).
Exceptions
`LUMEX_ASSERT`if an invalid variable type is encountered.

inline

Utility function to retrieve a variable from a set, handling scratch buffer for name.

This function takes a variable name that might not be null-terminated (given by begin and end), copies it into a scratch buffer (or allocates temporary heap memory if needed), and then looks up the variable in the provided XPathVariableSet.

Parameters
bufferA fixed-size character array used as a scratch buffer for the variable name.
setA pointer to the XPathVariableSet to search in.
beginA pointer to the beginning of the variable name in the query string.
endA pointer to one past the end of the variable name in the query string.
out_resultA pointer to an XPathVariable* that will receive the found variable, or nullptr.
Returns
true if the operation was successful (including memory allocation for scratch buffer), false if memory allocation failed. The out_result should be checked to see if the variable was actually found.
Warning
buffer must be large enough to hold (end - begin) + 1 characters. If not, a heap allocation occurs.

LUMEX_API T * Lumex::Xml::XPath::Variable::new_xpath_variable ( char_t const * name)
inline

Factory function to create a new XPath variable of a specific type.

This templated function allocates memory for a new XPathVariable instance (of a derived type like xpath_variable_boolean, _number, _string, or _node_set) and initializes its name.

Template Parameters
TThe specific derived XPathVariable type to create.
Parameters
nameThe null-terminated C-style string name of the variable.
Returns
A pointer to the newly created variable on success, or nullptr if memory allocation fails or if name is empty.
Warning
The caller is responsible for freeing the allocated memory using delete_xpath_variable.
