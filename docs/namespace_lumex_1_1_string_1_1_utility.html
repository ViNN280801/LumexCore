Detailed Description

Provides string manipulation and utility functions.

This namespace contains various helpers related to string processing, including the stringify functionality for converting diverse types to their string representations.

C++11/C++14 compatible alias for std::void_t.

std::void_t is a C++17 feature. This alias provides a backwards-compatible equivalent, primarily used for SFINAE (Substitution Failure Is Not An Error) techniques to check for the validity of expressions (e.g., whether a type is streamable).

◆ stringify() [2/2]

template<typename... Args>
std::string Lumex::String::Utility::stringify ( Args &&... args)

Converts a variadic pack of arguments to a single string (C++11 version).

This function concatenates the string representation of all provided arguments into a single std::string. It uses a static_assert with all_streamable<Args...>::value to enforce streamability at compile time. Argument expansion is performed using the expander array trick, typical for C++11 variadic templates.

Template Parameters
ArgsA variadic pack of types. A compile-time error will occur if any type is not streamable.
Parameters
argsThe arguments to be converted to string.
Returns
A std::string containing the concatenated string representations of the arguments. @complexity O(N) where N is the total length of the string representations of all arguments.
Note
This version does not have an explicit if constexpr optimization for empty packs; use the stringify() no-argument overload for that.
