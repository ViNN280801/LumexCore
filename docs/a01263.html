Detailed Description

< For RAII-managed pointers on base interface.

Enumeration of supported probability distributions for random number generation.

Expected specialization when the success value is absent (void).

In-place construction tag; C++11 has no std::in_place.

Class that mimics std::expected from C++23.

Wrapper that holds an error value for Expected.

Exception thrown when accessing a missing value or error in Expected.

Analogue of std::bad_expected_access from C++23. Thrown by value() or error() when Expected is in the wrong state (for example, calling value() on an object that holds an error).

Not thread-safe unless ErrorType itself is thread-safe.

Constructing BadExpectedAccess can be expensive if ErrorType has a heavy constructor or allocates. Thrown by value() and error().

Used to construct an Expected in the error state. Analogue of std::unexpected from C++23.

https://en.cppreference.com/w/cpp/utility/expected Holds either a value of type SuccessType, or an error of type ErrorType. Functions can return either a success result, or error information without exceptions for expected failures. The implementation uses a union to save memory and manually manages the lifetime of the stored objects.
Template Parameters

ErrorTypeError type.
Note
This implementation is not thread-safe by default. Accessing Expected from several threads without external synchronization is undefined behavior if SuccessType or ErrorType are not thread-safe.
Warning
Using Expected with types that have non-trivial constructors/destructors or allocate memory, may be slower than C++23 std::expected, because object lifetime is managed by hand.

Directly constructs the contained value inside Expected, avoiding extra copies or moves. Analogue of std::in_place_t from C++17.

Lets Expected be used for functions that either succeed without returning a value, or return an error. It is the analogue of std::expected<void, E> from C++23.

Template Parameters
ErrorTypeError type.
Note
Here has_value() means success without a returned value, and !has_value() means the object holds an error.

This enum defines the various statistical distributions that the NumberGenerator class can utilize to produce random numbers. Each enumerator corresponds to a specific distribution type from the C++ Standard Library's <random> header. Users can select the desired distribution when constructing or configuring a NumberGenerator instance.
