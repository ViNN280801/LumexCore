Detailed Description

Base class for all XPath variables.

This abstract base class defines the interface for XPath variables, allowing retrieval and setting of their values regardless of their specific XPath type (boolean, number, string, node-set). It also provides functionality for chaining variables in a linked list, which is used by XPathVariableSet.

Note
This class does not handle memory management for string values or node sets directly when setting values; it expects the underlying variable-specific structures (e.g., xpath_variable_string) to manage that. It is designed with non-copyable semantics to prevent accidental deep copies of potentially large data.
