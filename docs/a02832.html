Detailed Description

Parses XPath expressions into an Abstract Syntax Tree (AST).

This class implements a recursive descent parser for XPath 1.0 expressions. It takes an XPath query string, a set of variables, and a memory allocator to construct an AST that can then be evaluated. It handles various XPath constructs, including location paths, expressions, functions, and predicates.

Note
The parser relies on XPathLexer for tokenization and XPathAllocator for memory management of AST nodes. Error reporting is handled via xpath_parse_result_t.
Warning
The parser uses recursion; very deep or complex expressions might lead to stack overflow if kxpath_ast_depth_limit is exceeded.

LUMEX_PUBLIC_API XPathAstNode * XPathParser::parse_expression_rec ( XPathAstNode * lhs,
int limit )

Recursively parses binary expressions based on operator precedence.

This is a core part of the shunting-yard algorithm (or operator-precedence parsing) that handles binary operators like +, -, *, div, mod, =, !=, <, >, <=, >=, and, or, and | (union). It takes into account operator precedence to build the correct AST.

Parameters
lhsThe left-hand side XPathAstNode already parsed.
limitThe minimum precedence level for operators to consider at this level of recursion.
Returns
A pointer to the root XPathAstNode of the parsed binary expression chain, or nullptr on parsing error.
Note
This function is highly recursive and manages m_depth.
Warning
Ensures that the union operator (|) is only applied to node sets.
