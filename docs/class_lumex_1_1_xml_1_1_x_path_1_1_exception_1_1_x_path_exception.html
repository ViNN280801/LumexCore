Detailed Description

Exception class for XPath parsing and evaluation errors.

This class inherits from std::exception and provides detailed information about errors encountered during XPath operations, including the error message and the XPathParseResult which contains context about the error location.

Note
This exception is thrown when XPath parsing fails or when XPath evaluation encounters an unrecoverable error.
See also
Lumex::Xml::XPath::Parser::XPathParseResult for detailed error information.
