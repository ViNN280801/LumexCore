in_place_t Lumex::Core::Optional::in_place {in_place_t::init_tag{}}
constexpr

A constant of type in_place_t used for in-place construction.

This global constant is used as the first argument in LumexOptional constructors or emplace calls when direct construction of the contained value is desired.

LumexOptional<MyClass> opt1(Lumex::in_place, arg1, arg2); // Constructs MyClass(arg1, arg2)
LumexOptional<std::vector<int>> opt2(Lumex::in_place, {1, 2, 3}); // Constructs std::vector<int>({1, 2, 3})

◆ nullopt

nullopt_t Lumex::Core::Optional::nullopt {nullopt_t::init_tag{}}
constexpr

A constant of type nullopt_t used to represent an empty LumexOptional.

This global constant is the canonical way to initialize or assign an empty state to a LumexOptional object.

LumexOptional<int> opt1 = Lumex::nullopt;
LumexOptional<std::string> opt2; // Also initializes as empty
opt2 = Lumex::nullopt;
