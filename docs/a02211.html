Detailed Description

template<typename ValueType>
struct lumex::core::expected::result::success_t< ValueType >

Marker returned by success(value): success carrying a value.

The conversion is implicit by design - that is the point of the marker - and is removed by SFINAE when the target success type cannot be built from the stored value, so a wrong target is a compile error at the return, not a silent reinterpretation.

Template Parameters
ValueTypeStored success type (decayed, never a reference).
