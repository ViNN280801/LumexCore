Detailed Description

C++11 lightweight, non-owning view over contiguous wide character sequences.

This header provides a manual implementation of a wstring_view equivalent for C++11, offering a safe and efficient way to refer to wide string data without owning or copying it. It is designed to be similar in API and behavior to std::wstring_view introduced in C++17. The class ensures cross-platform compatibility (Windows, Linux, macOS) and relies exclusively on the C++11 standard library, ensuring exception-safety and thread-safety for concurrent read-only access. It is a zero-overhead abstraction that avoids dynamic memory allocation.

Note
This LumexWStringView class does not manage the lifetime of the wide character data it views. It is the user's responsibility to ensure that the underlying wide character sequence outlives the LumexWStringView instance. Using a LumexWStringView that refers to destroyed or out-of-scope data will lead to undefined behavior.
