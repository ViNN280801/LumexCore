Detailed Description

Represents a string view used by the XPath lexer.

This structure holds pointers to the beginning and end of a character sequence, effectively providing a non-owning view of a string. It is used by the XPath lexer to represent tokens found in the XPath expression.

Note
This is a lightweight view and does not manage the lifetime of the underlying character data. The character data must remain valid for the lifetime of XPathLexerString.
