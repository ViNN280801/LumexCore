Detailed Description

template<typename T>
struct safe_compare_impl_helper< T, T, typename std::enable_if< std::is_floating_point< typename clean_type_t< T >::type >::value >::type >

Специализация для одинаковых типов с плавающей точкой

Template Parameters
TТип с плавающей точкой для сравнения

Прямое сравнение без преобразований типов для максимальной производительности. Используется когда оба типа идентичны и являются floating-point типами.

Note
No-throw, максимальная производительность для floating-point типов
