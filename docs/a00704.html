Detailed Description

General preprocessor helpers: LUMEX_FUNCTION_NAME, LUMEX_STRINGIZE and LUMEX_CONCAT.

LUMEX_FUNCTION_NAME is the decorated name of the enclosing function: __FUNCSIG__ on Windows targets, __PRETTY_FUNCTION__ with GCC and Clang elsewhere, __FUNCTION__ otherwise. LUMEX_STRINGIZE(x) and LUMEX_CONCAT(x, y) expand their arguments before turning them into a string literal or pasting them into one token.
