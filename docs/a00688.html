Detailed Description

template<typename SuccessType, typename ErrorType>
class Expected< SuccessType, ErrorType >

Класс, имитирующий std::expected из С++23. https://en.cppreference.com/w/cpp/utility/expected.

Представляет собой объект, который может содержать либо значение типа SuccessType, либо ошибку типа ErrorType. Это позволяет функциям возвращать либо успешный результат, либо информацию об ошибке без использования исключений для ожидаемых сбоев. Реализация использует union для экономии памяти и вручную управляет жизненным циклом хранимых объектов.

Template Parameters
SuccessTypeТип успешного значения.
ErrorTypeТип ошибки.
Note
Эта реализация не является потокобезопасной по умолчанию. Доступ к Expected из нескольких потоков без внешней синхронизации может привести к неопределенному поведению, если SuccessType или ErrorType не являются потокобезопасными.
Warning
Использование Expected с типами, которые имеют нетривиальные конструкторы/деструкторы или выделение памяти, может быть менее производительным, чем std::expected из C++23, из-за ручного управления жизненным циклом объектов.
