Detailed Description

template<typename ErrorType>
class lumex::core::expected::error::BadExpectedAccess< ErrorType >

Exception thrown when the value of an Expected is read while it holds an error.

Analogue of std::bad_expected_access from C++23. Thrown only by value() of an Expected that holds an error; it carries that error. error() of Expected does not throw it: called without an error, it fails LUMEX_ASSERT and aborts the program.

Template Parameters
ErrorTypeError type stored in and retrievable from the exception.
Note
Not thread-safe unless ErrorType itself is thread-safe.
Warning
Constructing BadExpectedAccess can be expensive if ErrorType has a heavy constructor or allocates.
