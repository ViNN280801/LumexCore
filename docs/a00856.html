◆ file_type

enum class lumex::core::filesystem::fs::file_type : std::int8_t
strong

Enumeration of common file types, compatible with std::filesystem.

This enum provides a portable way to categorize file system entities, including regular files, directories, symbolic links, and various device or special files.

Enumerator
not_found 

The file system entry does not exist.

none 

No file type is specified (default constructed state).

regular 

A regular file.

directory 

A directory.

symlink 

A symbolic link.

block 

A block device file.

character 

A character device file.

fifo 

A FIFO (named pipe) file.

socket 

A socket file.

unknown 

The file type is unknown or could not be determined.

◆ perms

enum class lumex::core::filesystem::fs::perms : std::uint16_t
strong

Enumeration of file permissions, compatible with POSIX chmod masks.

These flags can be combined using bitwise operators to represent various access rights for the owner, group, and others. Special bits like Set-UID, Set-GID, and Sticky are also included.

Enumerator
none 

No permissions.

owner_read 

Read permission for the file owner.

owner_write 

Write permission for the file owner.

owner_exec 

Execute permission for the file owner.

owner_all 

All permissions for the file owner (read, write, execute).

group_read 

Read permission for the file's group.

group_write 

Write permission for the file's group.

group_exec 

Execute permission for the file's group.

group_all 

All permissions for the file's group.

others_read 

Read permission for others.

others_write 

Write permission for others.

others_exec 

Execute permission for others.

others_all 

All permissions for others.

all 

All standard permissions (owner, group, others).

set_uid 

Set-User-ID bit.

set_gid 

Set-Group-ID bit.

sticky_bit 

Sticky bit.

mask 

Mask for all standard permission bits.

unknown 

Permissions are unknown or could not be determined.
