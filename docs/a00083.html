Detailed Description

Resolves short, configuration-style serial-port names into the platform-specific path or identifier a communication channel actually needs in order to open them.

Handles the differences between how Windows, Linux and macOS name serial ports (COM1 vs. /dev/ttyUSB0 vs. /dev/serial/by-id/...), plus a couple of historical fallback quirks (see lumex::applied::serial::resolve_serial_port_path for the full list) that keep a slightly malformed configuration value from failing outright.
