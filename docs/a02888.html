Detailed Description

Why a document failed schema validation.

parse_error: the text is not JSON. missing_required: a required object or array is absent, or the value is not an object or an array where the schema requires one. type_mismatch: a leaf value does not match type. const_mismatch: a value differs from const. enum_mismatch: a leaf value is not listed in enum.

Carries the failure reason, the JSON path of the offending value ($.items[2].name) and a human-readable detail. what() is ‘[LumexJsonSchemaException] <reason> at ’<path>': <detail>`.
