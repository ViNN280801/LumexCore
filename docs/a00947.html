XmlDocumentBase derives from both XmlNodeBase (as a node_document node) and XmlAllocator, so the root of every tree is also the allocator that owns the tree's memory pages. It also keeps the buffers that the document and the fragments appended to it were parsed from, because names and values point into them. get_document finds the document that owns a node or an attribute through the memory page the object lives in.

The public type is XmlDocument, which holds this record.
