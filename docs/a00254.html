Detailed Description

Serializes a simple aggregate (no constructors, no private members, no base classes) to JSON by walking its fields.

The header parses as C++11 (tuple_size). Indexed get is C++14 (friend-injected field types). to_json needs field names, which LumexAggregateFields.hpp can recover only from C++20 (LUMEX_FUNCTION_NAME of a pointer NTTP). JSON is vendored nlohmann 3.12.0 at 3rdparty/nlohmann/json.hpp. Optional-like fields (has_value plus unary *) are omitted when empty, so both std::optional and optional work.
