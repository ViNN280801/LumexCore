Detailed Description

XML module: a DOM tree of nodes, attributes and text, loading and saving with writers for files and streams, and XPath queries with variables.

Link lumex::xml (shared library). Works from C++11; the std::string_view overloads appear from C++17 as inline wrappers over the exported functions. The umbrella includes the DOM classes, the writer interface and its file and stream implementations, the parse result, the XPath classes, the common types and constants, and XmlCleaner and XmlUtils.

The module is derived from pugixml (https://github.com/zeux/pugixml, MIT, Copyright (c) 2006-2026 Arseny Kapoulkine); its notice is in THIRD-PARTY-NOTICES.md, installed with the library.
