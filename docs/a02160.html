Detailed Description

Cross-platform crash dump handler with comprehensive debugging support.

This class provides a robust, thread-safe crash dump handler that automatically captures memory dumps when crashes occur on both Windows and UNIX platforms. It supports multiple dump types through the DumpFactory pattern and provides comprehensive debugging information for post-mortem analysis.

The CoreDumpGenerator offers:

  • Automatic crash detection and dump generation
  • Cross-platform compatibility (Windows/UNIX)
  • Multiple dump types and configurations
  • Thread-safe singleton pattern implementation
  • Comprehensive error handling and logging
  • Security-focused path validation
  • Atomic file operations to prevent race conditions
Invariant
The singleton instance is created only once and is thread-safe
All file operations are atomic to prevent TOCTOU race conditions
All input paths are validated for security vulnerabilities
Platform-specific handlers are properly initialized

@thread_safety This class is thread-safe. Multiple threads can call public methods concurrently without external synchronization.

@exception_safety All public methods provide strong exception safety guarantee unless otherwise specified. Methods marked noexcept provide no-throw guarantee.

Check if the current process is running with administrator privileges.

This method provides a cross-platform way to check if the current process has administrator/root privileges. On Windows, it checks both token elevation and membership in the Administrators group. On UNIX systems, it checks if the effective user ID is 0 (root).

Note

void lumex::core::utility::dump::CoreDumpGenerator::setAdminGroupName ( std::string const & name)
inlinestaticnoexcept

Sets the admin group name used by isAdminPrivileges() on UNIX.

LumexLib does not hardcode an admin group: the name defaults to empty, which leaves the root-only check in place. Passing a non-empty name makes members of that group count as admin too. A name that cannot be resolved with getgrnam() also falls back to the root-only check. On Windows this is a no-op.

Parameters
nameGroup name to treat as admin; empty disables the group check.
Note
This method is thread-safe.
