Detailed Description

Defines the LumexEnvironment class for cross-platform environment variable management.

This header provides the declaration for the LumexEnvironment class, which offers a unified, thread-safe, and exception-safe interface for interacting with system environment variables across different operating systems (Windows, Linux, macOS). It utilizes design patterns like Singleton and Strategy to ensure a robust and flexible architecture.
