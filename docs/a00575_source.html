51 // ====================== success() / failure() markers ======================
52 // Sugar for `return` in a function whose return type is already an Expected:
53 // `return success();`, `return success(value);`, `return failure(error);`.
54 // A marker carries what it was given and converts into any Expected the target
55 // declaration accepts; nothing about the marker is tied to one Expected type.
