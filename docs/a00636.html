LUMEX_PUBLIC_API uint8_t Lumex::Core::crc::Crc8::calculateCrc8 ( uint8_t const * data,
std::size_t size )
static

Вычисляет CRC8 для заданного буфера данных, представленного raw ptr и размером.

Эта функция является базовой реализацией CRC8. Она принимает raw ptr на данные и их размер. В случае некорректных входных данных (nullptr для данных или нулевой размер), она возвращает 0.

Parameters
dataУказатель на начало буфера данных. Должен быть действительным указателем, если size > 0.
sizeРазмер буфера данных в байтах.
Returns
Вычисленное значение CRC8 (uint8_t) или ошибка. Возвращает 0, если data == nullptr или size == 0.
