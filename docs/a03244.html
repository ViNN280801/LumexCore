Detailed Description

An IXmlWriter implementation that writes XML data to a file.

This class provides a concrete implementation of the IXmlWriter interface, enabling XML serialization directly to a file stream. It wraps a void* file handle, assuming the caller manages the underlying file lifecycle.

Note
This class does not own the file pointer; it's the caller's responsibility to open and close the file. It is not copyable or movable.
