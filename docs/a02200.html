Parameters
[in]expected_valueExpected current value
[in]desired_valueDesired new value
Returns
true if the value was changed, false if expected_value does not match the current value

Performs an atomic compare-and-set. For atomic types uses compare_exchange_strong with memory ordering. For non-atomic types performs a plain check-and-set.

Note
Thread-safe when Atomic=true; no-throw
Warning
expected_value may be updated on a failed compare (for atomic types)
