Detailed Description

A tag type used to indicate in-place construction of the contained value.

This structure mirrors std::in_place_t from C++17. It is used in LumexOptional constructors and emplace methods to signify that the contained object should be constructed directly inside the optional's storage using the provided arguments, rather than copying or moving an existing object. This avoids unnecessary temporary objects and can improve performance.
