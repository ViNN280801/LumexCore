LUMEX_PUBLIC_API std::vector< byte_type > Decoder::decode ( std::string const & encoded)
static

Decodes a Base64 string into binary data and returns it as a std::vector<byte_type>.

This is an overloaded function that provides a convenient way to decode a Base64 string and receive the result directly as a returned std::vector<byte_type>.

Parameters
[in]encodedThe Base64-encoded input string.
Returns
A std::vector<byte_type> containing the decoded binary data. Returns an empty vector if the decoding fails or the input string is invalid.

LUMEX_PUBLIC_API bool Decoder::decode ( std::string const & encoded,
std::vector< byte_type > & out )
static

Decodes a Base64 string into binary data and stores it in an output vector.

This function attempts to decode the given Base64 string. The decoded binary data is appended to the provided out vector. Before appending, the out vector is cleared to ensure it only contains the result of the current decoding operation.

Parameters
[in]encodedThe Base64-encoded input string.
[out]outA std::vector<byte_type> that will store the decoded binary data. It is cleared at the beginning of the function.
Returns
true if the decoding was successful and the input string was a valid Base64 format, false otherwise (e.g., invalid length, contains non-Base64 characters, or incorrect padding).
