◆ m_maxSIMDWidthBits

uint32_t Lumex::Applied::Hardware::cpu_vectorization_info_t::m_maxSIMDWidthBits

Maximum SIMD register width in bits.

Indicates the maximum SIMD register width supported by the CPU. This value helps determine the optimal vectorization strategy and buffer alignment requirements.

@unit Bits (e.g., 128, 256, 512)

Note
For x86/x64: 128 (SSE), 256 (AVX), or 512 (AVX-512)
For ARM: 128 (NEON) or variable (SVE)
Used for memory alignment and buffer size calculations

bool Lumex::Applied::Hardware::cpu_vectorization_info_t::m_supportsAVX

AVX (Advanced Vector Extensions) support.

Indicates support for AVX instruction set, introduced with Intel Sandy Bridge and AMD Bulldozer processors. Provides 256-bit SIMD operations for floating-point data types, doubling the width compared to SSE.

Return values
trueCPU supports AVX instructions
falseCPU does not support AVX instructions
Note
Present on processors since ~2011
Requires OS support for XSAVE/XRSTOR instructions
