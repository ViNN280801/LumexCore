Detailed Description

Recursive walker for a JSON Schema draft-7 subset.

Supported keywords: type (a string or an array of type names), properties, required, items (a single schema), const, enum. Everything else in the schema is ignored. The walker is API-agnostic: the validator and the normalizer base both call it.
