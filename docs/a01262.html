bool lumex::core::environment::env::is_env_set ( LumexEnvironment::string_type const &  name)

Checks whether an environment variable is set to a non-empty value.

A small free-function helper, equivalent to !LumexEnvironment::get_or(name, {}).empty(): true only when the variable exists and its value is not an empty string.

Parameters
nameName of the environment variable to check.
Returns
True if the variable exists and is non-empty, false otherwise.
Note
This function is thread-safe (delegates to LumexEnvironment).
Does not throw.

◆ is_env_truthy()

bool lumex::core::environment::env::is_env_truthy ( LumexEnvironment::string_type const &  name)

Checks whether an environment variable is "truthy" (enabled).

A small free-function helper, equivalent to LumexEnvironment::is_truthy(name). A variable is truthy unless it is unset, empty, or equal to "0"/"false" once lower-cased.

Parameters
nameName of the environment variable to check.
Returns
True if the variable is truthy, false otherwise.
Note
This function is thread-safe (delegates to LumexEnvironment).
Does not throw.
