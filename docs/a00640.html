LUMEX_PUBLIC_API LumexEnvironment::EnvResult LumexEnvironment::get_environment_variable ( string_type const & name) const

Convenience overload for get_environment_variable using std::string.

This method converts the std::string name to a C-string and delegates to the char const * overload.

Parameters
nameThe std::string name of the environment variable to retrieve.
Returns
An EnvResult object containing the variable's value and operation status.
Note
This method is thread-safe due to the underlying char const * overload.
Exceptions
Nothing(delegates exception safety to the underlying C-string overload).
