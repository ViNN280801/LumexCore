LumexSettingsFactory::create() maps a SupportedConfigExtensions value to a new LumexSettingsINI, LumexSettingsXML or LumexSettingsJSON owned by a std::unique_ptr. INI is always available. XML and JSON exist only when the settings library was built with LUMEX_SETTINGS_WITH_XML (the XML module) or LUMEX_SETTINGS_WITH_JSON (the vendored nlohmann/json header); for a format the build left out, the factory returns a null pointer.
