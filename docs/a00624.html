Detailed Description

template<class T, class Allocator = std::allocator<T>>
class Lumex::Core::CircularBuffer::CircularBuffer< T, Allocator >::iterator

Итератор случайного доступа над логической последовательностью элементов.

Этот итератор предоставляет функциональность для обхода элементов в CircularBuffer с возможностью случайного доступа. Он ведет себя как обычные указатели или итераторы стандартных контейнеров, таких как std::vector.
