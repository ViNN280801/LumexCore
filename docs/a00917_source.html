78 // building a shared library, so the utility DLL exports these symbols while
79 // every other DLL/executable imports them. Unlike the generic LUMEX_API (which
80 // keys off LUMEX_EXPORTS, defined for ALL shared targets), this pins symbols
81 // to exactly one module so header-only classes with out-of-line static data
