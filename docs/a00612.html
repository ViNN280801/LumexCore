LUMEX_PUBLIC_API bool Validator::is_valid_base64 ( string_type_t str)
static

Checks if a given string is a valid Base64 encoded string.

This function verifies the integrity of a Base64 string by checking its length, character set, and padding. A valid Base64 string must have a length that is a multiple of 4, consist only of Base64 alphabet characters and padding characters ('='), and have correctly placed padding at the end if present.

Parameters
[in]strThe string to be checked for Base64 validity.
Returns
true if the string adheres to Base64 formatting rules, false otherwise.
