enum lumex::core::crc::catalog::TransportCrcMode : std::uint8_t
strong

Process-global 8-bit transport checksum mode (one byte per frame).

Enumerator
Default 

CRC-8/MAXIM-DOW (Crc8MaximDow).

Catalog 

Catalogue entry from all_crc_specs_t with widthBits == 8.

Custom 

Caller-supplied crc_params_t; widthBits must be 8.
