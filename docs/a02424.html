Detailed Description

template<typename T, typename Char, typename Enable = void>
struct lumex::core::utility::traits::string::is_string_like< T, Char, Enable >

T is a contiguous string of Char: it has data() convertible to Char const *, size(), T::npos and T::value_type == Char.

True for std::basic_string, std::basic_string_view, LumexStringView / LumexWStringView; false for containers such as std::vector<char> (no npos).
